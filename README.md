# CollegeActivityTracker (Ledger)

A single-page web app for the Congressional App Challenge that evaluates whether
an activity strengthens a college application, tracks the ones that do on a
checklist, logs progress updates as bullet points, flags weak updates with an
improvement tip, and generates a "next step" suggestion per activity.

## Run it
Just open `index.html` in a browser — no build step, no dependencies.

## Stack
Plain HTML/CSS/JavaScript.
